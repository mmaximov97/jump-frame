# Шаблонный промт для чатов редизайна

Скопируй блок ниже в новый чат и впиши номер PR в первой строке.

---

Мы делаем редизайн FrameJump. Сначала прочитай `README.md` и `CLAUDE.md` — там описание продукта (что это, как считается прыжок, из чего состоит приложение). Потом прочитай `docs/redesign-roadmap.md` — там весь план редизайна и общие правила.

Твоя задача — **только пункт «PR-__»**. Другие пункты плана не трогай, даже если видишь, что рядом можно что-то улучшить.

Порядок работы:

1. **Сначала — никакого кода.** Составь подробный дизайн-план именно этого PR:
   - все элементы интерфейса, которые появятся или изменятся;
   - их состояния (обычное / нажатое / выключенное / пустое / ошибка);
   - поведение и расположение на экране;
   - крайние случаи (нет данных, длинное видео, маленький экран и т.п.).
   Опиши письменно, понятным не-разработчику языком. Сохрани копию плана в `tmp/plans/`.

2. **Покажи план мне и жди подтверждения.** Если я прошу что-то изменить — правь план и показывай снова. К коду не переходи без моего явного «ок».

3. После подтверждения: у этого чата должна быть **своя отдельная папка** (git worktree), а не общая `/Users/birka/Desktop/jump-frame` — иначе параллельные PR-чаты сбивают друг другу ветку и файлы на диске (было на PR-3, чинили постфактум). Проверь `git worktree list` в `/Users/birka/Desktop/jump-frame` — если папки для этого PR ещё нет, создай её командой (запускать из `/Users/birka/Desktop/jump-frame`, предварительно обновив `redesign`):
   ```
   git worktree add -b feat/<имя-ветки> ../jump-frame-worktrees/pr<N>-<короткое-имя> redesign
   ```
   Дальше вся работа этого чата — в новой папке `../jump-frame-worktrees/pr<N>-<короткое-имя>`, не в основной. Реализуй строго по подтверждённому плану. Если по ходу выясняется, что план надо менять — вернись ко мне с правкой плана, а не молча делай по-другому.

4. Проверь результат вживую через dev-сервер, обязательно на мобильной ширине экрана. Закоммить в фиче-ветку — **но не пуш и не PR**. Коммиты остаются локально, пока я явно не скажу «отправляй» / «пушь» в этом же чате. Не открывай PR по умолчанию, даже если это кажется логичным следующим шагом.

5. Расскажи, что сделано и что именно проверено, простым языком.

Обязательные ограничения из плана: тач-зоны интерактивных элементов ≥ 44×44 px; видео никогда не покидает браузер; цвет не единственный различитель (дублируй иконками); мобильный экран — приоритетный.
